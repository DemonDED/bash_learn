Глава 3. Исследование системы

Обзор команд к главе:

ls - выводит содержимое каталога
file - выводит тип файла
less - выводит содержимое файла для просмотра

------------------------------------------

У команды ls есть ряд дополнительных возможностей

ls ~ /usr

вывод содержимого для home/me и /usr

Так же есть возможность задать параметры

ls -t

Выведет содержимое текущего каталога отсортированного по времени (time)

-----------------------------------------

О параметрах и аргументах

В большинстве команд, особенно от проекта GNU, имеется возможность передать

1) Параметры - символы-сокращения которые сигнализирует команде о выполнении
дополнительных опций или функционала, обычно они предваряются дифисом, например:

ls -l --- "-l" это параметр, параметров может быть несколько "-lad" это три
разных параметра.

Так же есть параметры с длинными именами, они претваряются двумя дефисами

ls --help --- "--help" это параметр с длинным именем.

Аргумент это данные которые передаются команде, в контексе ls это путь к
каталогу, содержимое которого нужно вывести

ls -a /usr --- "/usr" это аргумент

-----------------------------------------

Самые популярные параметры для ls:

1) -a --all
2) -A --almost-all
3) -d --directory
4) -F --classify
5) -h --human-readable
6) -l
7) -r --reverse
8) -S
9) -t


----------------------------------------

Про параметр -l у ls

Параметр -l у ls позволяет вывести более подробную информацию, в длинном формате
(long), пример того, как это выглядит:

-rw-rw-r-- 1 ded ded 2123 Jul 30 16:00 theory_chapter_03.txt

Разберем по частям

1) -rw-rw-r-- -- это права доступа и тип файла

первый символ - тип файла, если "-", то это просто файл, если "d" то директория

Затем идет 9 символов:

1.1 rw- -- это права доступа владельца файла
1.2 rw- -- это права доступа группы владеющей файлом
1.3 r-- -- это права доступа для "всех остальных"

2) 1 -- это количество символьных ссылок
3) ded -- это владелец файла
4) ded -- это группа которой принадлежит файл
5) 2123 -- вес файла в байтах (добавив -h можно увидеть в более читаемом формате)
6) Jul 30 16:00 -- дата и время последнего изменения
7) theory_chapter_03.txt -- имя файла

------------------------------------------

"В Linux все сущее есть файл"

Это действительно так, и особенность в том, что нет как таковых расширений
файлов. Например файл image.jpg, не обязательно является изображением, .jpg есть
лишь просто часть названия.

Чтобы проверить точно тип файла в системе, есть специальная команда file

file имя_файла

Пример:

file theory_chapter_03.txt
theory_chapter_03.txt: Unicode text, UTF-8 text
